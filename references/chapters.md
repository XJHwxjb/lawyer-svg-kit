# chapters.md — 章节进度条（v0.9）

律师要求：成片加一条"章节进度条"——灰框横条分成 N 格，每格 = 本期口播的一部分内容，
讲到哪格哪格高亮，底部细线显示总进度。参考模板 = 抖音顶部章节条（引言 | 痛点 | 来源 …）。

**核心原则：章节由 AI 读懂口播稿后归纳，不是均分时长，不是把 SRT 逐句搬上去。**

## 1. AI 生成流程（每案必做）

1. **读完整口播稿/SRT**，先写一句话"本期在讲什么"，再找出语义转折点：
   开场引入 → 问题/痛点 → 原因/分析 → 方法/建议 → 总结/行动号召。
   转折以"话题变了"为准，不是以句子数量为准。
2. **归纳 3~6 个章节**（少于 3 格太空、多于 6 格竖屏放不下）。相邻小段话题相同就合并。
3. **起标签**：≤8 个汉字（4~6 字最佳），用观众听得懂的词：
   好：`引言` `彩礼痛点` `钱去哪了` `三步取证` `律师建议`
   坏：`第一部分` `SRT 1-8` `民法典1042条适用分析`（内部术语/超长）
4. **定边界**：start/end = 成片时间轴上的绝对秒点，取自 SRT 句边界（上一句结束 = 下一章节开始）。
   - 口播做过变速（如 1.1 倍速）时，SRT 秒点必须先乘变速系数换算到成片时间轴
     （例：原速 44.033s → 1.1x 39.636s，系数 ≈ 0.900），再填 chapters.json。
   - 第一章 start=0，最后一章 end=口播总时长；章节首尾相接，不留缝、不重叠。
5. **写 chapters.json** 到案件工程根目录（与 film.config.js 同级）：

```json
{
  "position": "top",
  "chapters": [
    { "label": "引言",     "start": 0,    "end": 5.2 },
    { "label": "彩礼痛点", "start": 5.2,  "end": 16.8 },
    { "label": "钱去哪了", "start": 16.8, "end": 28.5 },
    { "label": "律师建议", "start": 28.5, "end": 39.6 }
  ]
}
```

字段：
- `position`：`"top"`（默认，抖音模板位）| `"bottom"`。律师明确要底部时才用 bottom；
  bottom 时字幕 MarginV 要再抬高，别和条打架。
- `chapters[]`：`label`（≤8 字）/ `start` / `end`（秒，end > start）。

## 2. 渲染与合成（自动，无需改代码）

- `node render.cjs` 检测到 chapters.json 就注入合成页：灰框横条画在 worldA/B 与颗粒之外，
  转场淡化不影响它；每帧按 `t = 帧号/fps` 更新高亮格与进度线（纯时间函数，确定性）。
- 格宽 ∝ 章节时长，保底放得下标签（超宽自动整体压缩）；标签字号随格宽自适应。
- 当前格：白色半透明底 + 标签加粗全亮；其余格标签 72% 亮度；格间白色细分隔线。
- 底部 4px 进度线：已讲部分白色实心，未讲部分 22% 白。
- **没有 chapters.json = 不画条**（v0.8 旧工程照常渲染）。
- compose.sh 不需要任何改动——条已经烧进帧序列。
- film.info.json 会附带 chapters，供验收对轨。

## 3. 验收（不通过不交付）

1. 停帧抽查 3 点（每章各取中间时刻）：`ffmpeg -ss <秒> -i out/成片.mp4 -frames:v 1 chk.jpg`，
   打开图片核对：高亮格标签 = 当时口播正在讲的话题；进度线位置 ≈ 已播比例。
2. 标签逐字核对口播稿：不得出现稿件没有的事实/数字；不得用内部术语。
3. 竖屏 6 格时检查最窄格标签是否完整（字号自适应后仍应可读，不小于 20px）。
4. 转场帧（交叉淡化期间）条不闪、不淡出。
5. 无 chapters.json 的工程：确认画面无条、无报错（向后兼容）。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 条没出现 | chapters.json 不在工程根目录 / JSON 语法错（render.cjs 会报错）/ chapters 为空 |
| 高亮格与口播对不上 | 边界秒点没换算变速系数，或章节划分脱离语义；重读 SRT 重划 |
| 某格标签被截断 | 标签超 8 字或格数太多；缩短标签或合并章节到 ≤6 |
| 条压住剧情 | 条默认顶部 88px（竖屏）/64px（横屏）；竖屏标题安全区本就预留上方，剧情贴地不受影响；若自定义天空 UI 顶到条，下移 UI |
| 律师要底部条 | position 改 bottom，同时字幕 MarginV 抬高避开 |
