# 成片验收

对导出的文件验收，别只检查工程预览。保留检查命令、截图或报告，便于复核；不要虚报未执行的项目。

验收分两级：**资产级**——案件用到的主库动作已在预览台按选定画幅通过 t-sweep（见 [studio.md](studio.md)）；**成片级**——本文件，针对最终渲染的 MP4。资产级通过不能替代成片级。

1. **素材与时间轴**：核对总时长、帧率、画幅（= 项目选定的单一画幅）、音视频流与编码，检查片头片尾没有被截断；逐句对照字幕源文与时间戳，播放对照原声音，处理漂移、错字、溢出与遮挡。口播视频的画面和声音应保持同步，若为刻意裁剪须保持语义完整。
2. **声音**：播放开头、中间、结尾及加音效处，确认原声完整、音画同步、无削波或明显突兀的音量变化；确认音效对齐动作接触/冲击帧、不压口播（sound.md 两层：口播+音效，无 BGM）。**转场/翻页应静音**（whoosh 已移除）；句间自然停顿合法，不再要求全片连续有声。用波形比对或抽样相关性辅助发现错位，不能代替听检。核对来源与授权：音效查 `assets/sfx/LICENSES.md` 与 manifest.json；合成兜底（make_sfx）必须有向用户声明的记录。
3. **画面与动作**：从最终文件按场景关键帧及固定间隔抽帧，覆盖开头、转场、结尾；检查黑帧、闪烁、文字截断、视觉拥挤、道具遮挡、越框与行为是否对应口播。对递交、位移和停顿等动作片段连续播放或加密抽帧，不以稀疏静帧代替动作检查。机器黑帧检测是辅助，不能代替视觉审片。
4. **正确性与交付**：核对价格、数据、名称、案件事实及引用来源（全部应为稿件值，不得残留库内演示默认值）；素材缺失或存在未解决差异时明确说明。记录输出路径、时长、格式和已知限制。交付可播放文件与工程；不要将私人素材或工程上传到公共仓库。

## 可执行门禁（v0.5，先跑命令再人工复核）

以下命令在案件工程目录执行，输出存进 `qa/`。命令通过 ≠ 验收通过，仍须实听实看；命令不通过则必须修复后重跑。

**1) 冻结门禁（反幻灯片，SKILL.md §0.6）**

```bash
ffmpeg -i out/成片.mp4 -vf freezedetect=n=-60dB:d=0.5 -an -f null - 2>&1 | grep -E "freeze_(start|end|duration)"
```

列出所有 ≥ 0.5s 的静止段。每一段都必须能解释：合法静止只有**结尾淡出**；数字阅读停留不应触发（`hold` preset 带 1% 漂移）。出现未解释的冻结 = 有镜头入场后死住，回 film.config.js 给该镜头加 camera 或动作，重渲。

**2) 数字停帧抽查（SKILL.md §0.5）**

对每个关键金额：从分镜/film.info.json 找到它的停稳窗口（count-up 结束 → 转场开始），在窗口内任取 2 个时刻抽帧：

```bash
ffmpeg -ss 12.5 -i out/成片.mp4 -frames:v 1 qa/num-12.5.jpg
ffmpeg -ss 13.4 -i out/成片.mp4 -frames:v 1 qa/num-13.4.jpg
```

打开图片读数字：**必须精确等于稿件值**（不是近似值、不是累加中间值），标签（约定/实付/判决）同帧可见。两帧读数不一致 = 计数未停稳或在做滚动合计，不合格。

**3) 数字停留时长测量**

停稳窗口 = 镜头时长 × (1 − count-up 结束的 t01)，必须 ≥ 1.2s。配置层可直接算（film.config.js 的 dur 与自定义动作的 COUNT_END）；成片层在窗口前后以 5fps 抽帧确认精确值可读的帧数 ≥ 6：

```bash
ffmpeg -ss 12.0 -t 2.5 -i out/成片.mp4 -vf fps=5 qa/hold-%02d.jpg
```

**4) 转场抽查**

从 film.info.json 读每个镜头的 startFrame/fps 得到边界秒点，抽边界前后相邻帧（如 ±0.1s）：应看到交叉淡化的中间态（两画面叠加），而不是硬切或闪黑。Remotion 路线抽 DocumentTransition 的关键帧。

**5) 音效核对（v0.8 两层：口播+音效，无 BGM）**

```bash
# events.json 非空、秒点都在成片时长内；mixed.wav 峰值不过载
ffmpeg -i mixed.wav -af astats=metadata=1 -f null - 2>&1 | grep "Peak level"
# 音效可闻：events.json 任取 3 个秒点，±0.15s 窗 RMS 应明显高于相邻无事件窗
ffmpeg -ss 4.4 -t 0.4 -i out/成片.mp4 -af astats=metadata=1 -f null - 2>&1 | grep "RMS level"
```

mix_sound.py 输出的 `sfx_missing` 必须为空（events 引用了 sfx 目录里不存在的名字 = 有音效被静默跳过）；峰值 ≤0.98 线性不过载。**events.json 里不得出现 `sfx=="whoosh"`**（转场/翻页应静音；有 = 用了旧模板/旧 actions.js，更新到 v0.8 重渲）。再实听音效密集处：音效对齐可见动作（纸落/槌落/钱到），不压口播；翻页/转场处没有"呼"声。完全无音效的片子必须有向用户声明的记录。

**6) 五秒点耳机听检（v0.8，命令过了也不豁免）**

戴耳机逐点听：① 开头第一秒（淡入+第一个接触音）② 关键数字 ching 处（到账感、不压口播）③ 敲槌/盖章冲击处（砸实感、对齐画面）④ 音效最密集处（不糊、不炸）⑤ 收尾淡出。再抽听开头/中段/收尾各一段，确认口播清晰、真实录音无爆音/截断、**翻页/转场处静音（无"呼"声）**、句间自然停顿正常（无 BGM）。记录听检结论。

> v0.8 已退役的旧门禁：BGM 连续性（silencedetect 必须 0）、ducking ≈10dB 摆动、bgm.credits.json 许可台账——因为不再加 BGM。句间静音现在合法；silencedetect 只用于排查**异常**长静音（整段口播丢失），不是"必须为 0"。音效来源台账仍查 assets/sfx/LICENSES.md + manifest.json（CC0 为主，2 条 MIT 合成音声明已附）。

## 逐镜头复核：不要只检查文件能播放

用下面的表格检查实际导出的画面，而不是只对照分镜备注或代码。案件数字来自用户材料；以下是检查方法，不是对任何案件事实的认定。

| 核对项 | 具体做法 | 不通过时 |
| --- | --- | --- |
| 事实及金额 | 建立「原句及时间、主体、数值、含义、画面文案/图形、出现时间」对照表。分别记录约定、请求、实际支付、留存和判决金额；没有证据的数字留空。| 修正或移除该图文，口径无法判断时向用户核对；不能把约定值写成实付值。 |
| 人物与行为 | 对每个重要行为记下谁做、对谁做、道具从哪里到哪里；对照实际画面逐项检查。 | 修正主体、方向或动作；不确定的事实改为中性示意。 |
| 动作完成度 | 抽查递交前、伸手、接触、转移、接住、结束等关键状态；物体不能一直粘在原持有人手里。 | 修复后从最终视频重新抽帧或播放，不能只把备注写成"已递交"。 |
| 时间和节奏 | 核对重要数字、结论、图示揭示时机与原话；检查长时间静止或连续相似布局，挑选 3 个不同段落做连续观看。 | 让信息随语义出现；用动作、镜头、构图变化推进，不靠无意义闪烁凑动态。 |
| 图标与手机阅读 | 核对图案有无对应含义、是否真有分部动作；缩小预览检查标签、字幕和证据图形可辨。 | 调整大小、分镜和动画；不用为了凑数调用全部图案。 |
| 镜头与转场 | 分别抽看镜头起点、运动中段、终点，以及前后相邻帧；确认焦点与运动方向一致，道具的位置、朝向和比例衔接。字幕、头像和真人在运动期间始终留在画幅及安全区。 | 道具跳位、镜头切换闪黑或字幕被遮挡时修正后再渲染；不要通过静止截图推断运动流畅。 |
| 画面节奏 | 分别审查开头、案件经过、法律分析及结尾：连续画面里是否只剩文字、图标反复入场后停住，人物的行为是否随当前口播变化。 | 为有必要的语义节点补足行为、景别或素材变化，必要处保留阅读停顿；不靠全程摇晃、频繁切换来制造热闹。 |
| 导出整洁 | 检查字幕和人物无截断，移除时间码、调试文案与审片标注。 | 修正成片并重新检查。 |

记录已完成和未完成的检查。只比较 RMS、峰值或静音点并不能证明音轨逐样本一致或完全同步；未实时播放或未人耳听检时如实说明。若无法播放，连续抽帧、波形比对与工具检查只作为替代性证据，不能声称已完成观看和听检。

## 声音设计

完整规则见 [sound.md](sound.md)（v0.8 声音两层：口播+真实录音音效，**无 BGM**、转场/翻页静音、每镜头 ≥1 接触/冲击音效；优先级口播>音效）。优先保证口播清晰；音效触发点对应实际接触或动作完成帧（主库导出 JSON 的 `events[].at × dur` 即秒点；pipeline 路线由 render.cjs 自动产出绝对秒点 events.json，**只含动作内置接触/冲击音效，不含转场 whoosh**）。素材：`assets/sfx` 真实录音库（CC0 为主，默认 7 音+100 条备选，无 whoosh）、`scripts/mix_sound.py` 口播+音效两层混音（ogg/mp3 自动 ffmpeg 解码，无 BGM/ducking）；`scripts/make_sfx.py` 仅为离线兜底合成音（7 音）。不要每个字幕都配音效；转场/翻页不配音。仅用来源和授权清楚的素材（禁止从平台视频抽音频）；句间自然停顿合法（无 BGM）。分别检查开头、中段、结尾及音效密集处，并如实报告是否做过听检。

可用 `ffprobe -v error -show_streams -show_format -of json OUTPUT.mp4` 读取参数。先新建 `qa` 目录，再执行 `ffmpeg -i OUTPUT.mp4 -vf "fps=2/3,scale=384:-2" -q:v 3 qa/frame-%04d.jpg` 生成定间隔缩略图；该命令适用于常见 Windows、macOS、Linux shell，若路径含空格需用引号。核验音轨、源 SRT 和实际内容仍需另做。
